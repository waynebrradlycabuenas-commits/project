## Features
- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Status
- Darkmode

## Setup
1. composer install
3. Copy `.env.example` to `.env` and set your database credentials.
4. Run `php artisan key:generate`.
5. Run `php artisan migrate`.
6. Run `php artisan serve` and visit `http://127.0.0.1:8000`.
